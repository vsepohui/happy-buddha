====== Crypter-Tools ======

Набор из утилит и библиотек программиста для безопасной работы за компьютером - https://github.com/vsepohui/Crypter-Tools

В пакет входят утилиты:

  * crypter - приложение для шифрования данных на ЭВМ
  * crypted-note - безопасный шифрованный блокнот
  * piped - утилита для шифрования трафика в сети

А так же модули на Perl:

  * Strong::Random - безопасный генератор случайных чисел
  * Crypter - библиотека для шифрования данных

Модуль для С++:

  * librandom++ - безопасный генератор случайных чисел
